# AI Resume Analyzer

> An AI-powered resume analysis platform that evaluates resumes, identifies skills, recommends suitable job roles, and analyzes resume-to-job compatibility using Google Gemini.

---

## Overview

AI Resume Analyzer is a Python-based web application designed to help students and job seekers understand the strengths and gaps in their resumes.

The application uses **Google Gemini Generative AI** to analyze uploaded PDF resumes and generate structured career insights including:

- Overall resume score
- Detected technical and professional skills
- Missing or recommended skills
- Suitable job roles
- Resume improvement suggestions
- Target job compatibility
- Job-specific skill gaps
- Downloadable analysis report

The application provides an interactive interface using **Streamlit** and generates professional PDF reports using **ReportLab**.

---

## Key Features

### Resume Analysis
- Upload resumes in PDF format
- Extract resume content automatically
- Analyze resume quality using Generative AI
- Generate an overall score from 0–100

### Skill Analysis
- Detect technical skills
- Detect professional skills
- Identify missing or recommended skills

### Job Role Recommendation
Recommends the most suitable roles based on the candidate's resume.

For example:

| Job Role | Match |
|----------|-------|
| Full Stack Developer | 88% |
| Frontend Developer | 85% |
| Data Analyst | 75% |

### Target Job Matching

Users can optionally provide a job description.

The system compares the resume with the target role and provides:

- Job compatibility score
- Matching skills
- Missing job-specific skills
- Targeted improvement suggestions

### AI Resume Suggestions

Generates practical recommendations to improve:

- Resume content
- Project descriptions
- Technical skills
- Quantifiable achievements
- Job-specific relevance

### PDF Report

Users can download a structured resume analysis report containing the generated insights.

Module Responsibilities

Handles the Streamlit user interface, resume upload, job description input, analysis display, error handling, and report download.

resume_parser.py

Extracts text from uploaded PDF resumes.

ai_analyzer.py

Connects to the Google Gemini API and performs resume analysis, skill detection, job-role matching, and target-job analysis.

report_generator.py

Generates a downloadable PDF containing the resume analysis results.

requirements.txt

Contains the Python dependencies required to run the application.

Installation
Prerequisites

Make sure the following are installed:

Python 3.10+
Git
Google Gemini API Key
1. Clone the Repository
git clone https://github.com/your-username/AI-Resume-Analyzer.git
2. Navigate to the Project
cd AI-Resume-Analyzer
3. Create a Virtual Environment
python -m venv venv
4. Activate the Virtual Environment

Windows

venv\Scripts\activate

macOS / Linux

source venv/bin/activate
5. Install Dependencies
pip install -r requirements.txt
Environment Configuration

Create a .env file in the project root:

GEMINI_API_KEY=your_gemini_api_key

Replace your_gemini_api_key with your own Gemini API key.

Security: Never commit the .env file or expose your API key publicly.

Running the Application

Start the Streamlit application:

streamlit run app.py

The application will be available through the local Streamlit URL shown in the terminal.
